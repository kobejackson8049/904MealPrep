ADD A COMPLETE ADMIN / BUSINESS OPERATIONS DASHBOARD FOR 904 MEAL PREPZ.

This dashboard is for the business owner only and should be separate from the public customer website.

The purpose is to help them manage a high volume of weekly meal-prep orders without relying on Facebook messages, text threads, screenshots or manual counting.

Create a secure admin area with a professional dashboard UI.

CORE ADMIN FEATURES:

1. WEEKLY OVERVIEW

Show:

* total weekly orders
* total meals sold
* total revenue
* average order value
* pickup orders
* delivery orders
* premium meals sold
* new customers
* returning customers

2. KITCHEN PREP SUMMARY

Automatically total the exact quantity required for each meal on the current weekly menu.

Example:
#1 Breakfast Bowl — 18
#2 Biscuits & Gravy — 11
#3 Steak Croissant — 16
#4 Teriyaki Chicken — 27

Allow the owner to click a meal and see every customer who ordered it and their quantity.

Include a printable/exportable kitchen prep view.

3. ORDER MANAGEMENT

Create an orders table/list containing:

* order number
* customer
* phone
* email
* meals ordered
* total meals
* meal subtotal
* premium charges
* delivery charge
* final total
* pickup/delivery
* fulfillment window
* payment status
* order status
* order date

Order statuses:

* New
* Confirmed
* Preparing
* Ready
* Out for Delivery
* Completed
* Cancelled

Allow clicking an order for full details.

4. CUSTOMER MANAGEMENT

Maintain customer profiles containing:

* name
* phone
* email
* delivery address
* total lifetime spend
* total orders
* average order value
* last order date
* favorite meals
* pickup vs delivery history

5. WEEKLY MENU MANAGEMENT

Allow the admin to create/edit the weekly menu without editing code.

They should be able to:

* set the menu week
* set order cutoff date/time
* add/remove meals
* upload meal image
* edit meal number
* meal name
* description
* category
* calories
* protein
* carbs
* price
* premium charge
* mark meal unavailable/sold out

6. ANALYTICS

Show useful business analytics:

* revenue by week
* orders by week
* meals sold by week
* average order value
* top-selling meals
* lowest-selling meals
* top breakfast meals
* top entrée meals
* premium meal performance
* pickup vs delivery percentage
* new vs returning customers
* top customers by spend
* repeat customer rate
* delivery revenue

Use clean charts and simple visual reporting.

7. POPULAR MEALS

Maintain historical meal performance across multiple weekly menus.

Show:

* all-time units sold
* times meal appeared on menu
* average quantity sold each appearance
* revenue generated by meal
* last time meal appeared

This is important because menu items rotate weekly.

8. FULFILLMENT / DELIVERY VIEW

Separate pickup and delivery orders.

Delivery view should show:

* customer
* address
* phone
* total order
* delivery fee
* selected delivery window
* delivery status

Make it easy to organize Sunday and Monday delivery routes.

Do not build complex live GPS routing yet.

9. PAYMENT TRACKING

Track:

* paid
* unpaid
* refunded
* partially refunded if supported later

The architecture should be ready to connect to Square checkout later.

10. EXPORTS

Allow export of:

* weekly orders CSV
* customer list CSV
* kitchen prep summary CSV
* revenue report CSV

IMPORTANT ARCHITECTURE NOTE:

Unlike the public demo cart, the real admin/order system needs persistent data.

Do NOT use MemStorage or Replit runtime memory.

Structure the application so persistent production data can use a portable PostgreSQL-compatible database owned by the client.

Do not hard-wire the production system to Replit Database.

Create a clean data model for:

* users/admins
* customers
* weekly menus
* meals
* orders
* order items
* delivery information
* payment status

Keep database configuration environment-based and portable for later deployment to Vercel-compatible infrastructure.

Do not expose secrets.

Do not break the existing public website, weekly-menu selector, cart/order builder, images, videos or Vercel portability work.

DESIGN:

The admin dashboard should feel premium, clean and easy enough that a busy meal-prep owner can understand it immediately.

Prioritize operational clarity over flashy effects.
