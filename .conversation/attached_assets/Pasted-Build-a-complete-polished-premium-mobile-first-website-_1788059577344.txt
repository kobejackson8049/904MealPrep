Build a complete, polished, premium, mobile-first website concept for a local Jacksonville meal-prep business called 904 Meal Prepz.

This website is being created as a sales demo that may later be handed off to the actual business owner, so it must look extremely professional, creative, modern, trustworthy, conversion-focused, and ready for a clean GitHub/Vercel handoff.

Do NOT make this look like a generic restaurant template or a cheap AI-generated website.

The goal is that when the owner sees the website, their reaction is:

“This looks like my business already leveled up. I want this.”

Use the existing 904 Meal Prepz social-media branding and uploaded media as inspiration.

IMPORTANT TECHNICAL REQUIREMENT — PORTABLE FROM DAY ONE

This project MUST be intentionally designed for easy transfer:

Replit → GitHub → Vercel → client-owned domain

Do not create unnecessary dependencies on Replit.

Do NOT use:

* Replit Object Storage
* Replit-specific image URLs
* temporary upload URLs
* MemStorage
* Replit-only runtime APIs
* Replit-only database functionality
* Replit deployment URLs inside the application

All supplied photos, logos, menu graphics, and videos that are part of this demo should be stored directly inside the repository in organized public/static folders.

Use a structure similar to:

/public/images/

/public/images/meals/

/public/images/menu/

/public/images/brand/

/public/videos/

Reference assets using root-relative URLs such as:

/images/meals/teriyaki-chicken.jpg

/videos/meal-prep.mp4

These files MUST be tracked by Git so they automatically transfer to GitHub and deploy to Vercel.

Before completing the project, verify that the production build actually includes every media asset.
